# Evaluating supervised concept drift detection for online imputation on wearable data streams with changing missing mechanisms

## Overview

This repository contains experiments on supervised concept drift detection on online imputation
task applied to wearable COVID-19 datasets.

## Project Structure
<pre>
/
│
├── Data/                      
│   # Due to size constraints, the original datasets must be downloaded separately.
│   # Simulated data can be generated by running the scripts on the original data.
│
├── Imputation/                   
│   # Outputs and performance metrics for the imputation analysis
│   ├── Analysis/           
│   │   # Final imputation results using imputation methods (.csv files and plots)
│   └── Parameters/
│       # Parameter analysis for supervised concept drift detection (.csv files and plots)
│
├── Missing Simulations/
│   # Pipelines to simulate missing data on the original dataset
</pre>
## Installation

Clone the repository:

git clone https://github.com/afonsoMatheus/MMD-Wearables

Install dependencies:

Python 3.11.14
